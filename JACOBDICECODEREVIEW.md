# RV Campground Booking App

## Project Description
The RV Campground Booking App is a platform designed to let users easily search for campsite availability, compare site options, and complete bookings with clear confirmation and cancellation policies.

## Key Features
* **Search & Availability:** Users can filter available campsites based on check-in/out dates, park destination, and specific rig requirements (length and power hookups).
* **Site Selection & Pricing:** Provides a transparent price breakdown, including daily rates, taxes, service fees, and the ability to apply promotional codes.
* **Secure Booking & Payment:** Collects guest and rig information, processes payments securely (mocked for MVP, transitioning to Stripe), and issues a Booking ID and email receipt.
* **Manage Booking:** Users can view their itinerary, modify dates (if available), and process cancellations based on the campground's refund window.

## Technology Stack & MVP Scope
* **Frontend:** Client-side forms with keyboard-navigable date pickers and screen-reader accessibility.
* **Backend:** Mocked API using JSON for MVP (transitioning to real API in future iterations).
